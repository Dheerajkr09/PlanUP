Privacy Policy

Last Updated: October 2026

1. Overview

PlanUp is a Chrome extension designed to help users plan and manage YouTube playlists and one-shot videos by splitting them into manageable daily goals and tracking progress locally within the browser.

Your privacy is important. PlanUp is built with a privacy-first approach and operates entirely within your browser.

2. Information We Collect

PlanUp does not collect, store, or transmit any personally identifiable information.

The extension may access and process the following data locally within your browser:

  • YouTube playlist metadata (video titles, durations, playlist structure)
  • User-created planning configurations
  • Progress tracking information related to course completion

This data is processed only to provide the core functionality of the extension.

3. How Data Is Used

All data accessed by PlanUp is used strictly to:

  • Generate structured daily viewing plans
  • Track watch progress
  • Restore active plans
  • Maintain streaks and XP data

Data is processed locally in your browser and is not transmitted to any external servers.

4. Data Storage

PlanUp uses the Chrome storage API to store:

  • Playlist planning metadata
  • Progress state
  • Streaks, XP, and notes
  • Active plan restoration information

All stored data remains on the user's device and is never sent to any third-party servers.

5. Data Sharing

PlanUp does not:

  • Sell user data
  • Share user data with third parties
  • Transfer data outside the browser
  • Use data for advertising or tracking
  • Use data for profiling or analytics

6. Remote Code

PlanUp does not execute remote code. All executable scripts are bundled within the extension package distributed through the Chrome Web Store.

7. Third-Party Services

PlanUp does not use analytics tools, advertising networks, external APIs that collect user data, or tracking scripts.

8. Permissions Explanation

PlanUp requests access to youtube.com solely to inject a progress tracking widget and read playlist metadata necessary for generating viewing plans. No other websites are accessed.

9. Children's Privacy

PlanUp does not knowingly collect personal information from children under 13 years of age.

10. Changes to This Policy

If PlanUp's functionality changes in the future in a way that affects data usage, this Privacy Policy will be updated accordingly.
